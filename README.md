## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Slayblade**. This trainer enhances Slayblade's single-player runs by modifying cash, unlocks, combat survivability, and battle-top progression. It is designed around the game's core systems of collecting parts, merging powers, purchasing upgrades, and battling opponents.

**Target Audience:** Players who want to experiment with battle-top builds, test part combinations, reduce repetition, or enjoy relaxed single-player runs.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Slayblade uses mouse-driven controls and can be played with the mouse and left-click. Use the trainer while the game is running and avoid activating options during transitions between city areas, shops, and battles.

### Tools & Inventory

Use unlimited cash and unlock features to access more of the game's collectible battle-top parts. Combine different parts and merged powers to test alternative builds, then disable progression-related options before purchasing or saving important upgrades.

### World & Environment

Runs take place in a miniature Y2K-style city where players skate between activities, earn cash, purchase upgrades, and work toward becoming King of the Streets. The trainer is best used after a run has loaded fully.

### Combat & Weapons

Battle opponents with the configured Slayblade and its selected parts. Unlimited Health and Unlimited Spin support extended fights, while Instant Victory ends the active encounter. Disable combat options before starting another battle or returning to the city.
